# 매도·보유·교체 전략 재검토 — 2026-09-29

## 결론과 범위

좋은 신규 후보 때문에 기존 보유를 교체하는 기능은 연구할 가치가 있다. 현재는 후보와 보유를 비교하는 포트폴리오 판단이 없고, 5자리 상한에 도달하면 신규 진입을 거절한다. 다만 교체 횟수나 투자 비중을 늘리는 것만으로 전략의 수익성이 개선되었다고 판단할 수 없다.

권장 방향은 **보호 목적의 매도 → 기존 전략의 청산 → 남은 보유의 가치 평가 → 비용과 위험을 고려한 제한적 교체**다. 20일선 회복 전량 청산은 비교 기준으로 보존하고, 추적 손절을 쓰는 별도 매도 정책과 비교한다. 보유 수 확대, 청산 정책 변경, 교체 도입의 효과를 따로 측정한다.

이번 작업은 현행 소스·원시 재생 결과·기존 검토문서·외부 일차 자료를 조사하고 수정안을 제시한 것이다. 실행 코드와 운용 설정은 변경하지 않았다. 외부 주문 없이 별도 로컬 합성 계좌에서 실행 오류 두 건을 재현했다. 감자 등 기업행동 누락 때문에 현재 실제 자료의 성과 검증은 계속 차단되어 있다.

### 손절과 이익 보호

초기 손절을 무조건 좁히면 위험 기준 수량이 커지므로 손절 배수와 수량 정책을 같이 평가한다. 특히 ATR/가격이 너무 크거나 가격 단위가 불확실하면 매수 대상에서 제외하는 기준을 검증해야 한다. 기업행동 누락을 손절 폭 축소로 보정하지 않는다.

추적 손절 후보는 다음과 같이 정의한다.

```text
H[t] = 진입 이후 t일까지 공개·확정된 최고 종가
S[t] = max(S[t-1], H[t] - k × ATR[t])
t일 종가로 갱신한 S[t]는 다음 세션부터 적용
```

추적 손절은 보호선을 낮추지 않는다. 활성화 시점은 “20일선 회복 후” 또는 “초기 위험 대비 일정 이익 확보 후” 중 소수의 사전 정의 정책으로 비교한다. 고가·저가의 순서를 알 수 없는 일봉에서 당일 고가로 손절선을 높인 뒤 그날 저가에 체결됐다고 가정하지 않는다. 분할·감자 시 가격·수량·원가·초기 위험·최고 종가·손절선의 기준 단위를 함께 조정한다.

장중 보호 손절은 별도 실행 모드다. 일봉 종가 청산과 관측한 분봉/호가 기반 장중 청산을 같은 결과로 표시하지 않는다. 손절 주문은 가격을 보장하지 않으며 지정가를 사용하면 미체결이 생길 수 있다. [SEC 주문 설명](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins-15). 이는 주문 원리 참고이며 국내 브로커가 해당 주문 유형을 제공한다는 근거가 아니다.

### 시간 청산과 전략의 성격

10거래일 일괄 청산은 기준선으로 유지하고 5·10·20거래일의 소수 대안을 비교한다. 이후 “진전 없는 보유 조기 청산”과 “회복 후 추세 보유 연장”을 분리해 검증한다. 연장 정책에도 최종 기한을 두어 매일 초기화되는 무기한 보유가 되지 않게 한다.

현재 일 손실 1%는 신규 진입 중단 조건이다. 시장 급락 대응은 장후 시장 상태에 따른 신규 위험 축소, 이미 제출한 미체결 매수의 취소 확인, 기존 보유를 줄일 조건과 규모, 재개 조건을 각각 정해야 한다. 시장/계좌 신호가 보유 축소를 뜻하는지 관찰만 뜻하는지 명확히 하고, 네트워크 장애나 새 후보 부재를 전량 청산 신호로 해석하지 않는다. 구체적인 계좌 손실·시장 상태 임계값은 이번 조사에서 확정하지 않는다.

SMA20에서 파는 눌림목 회복 전략과, 회복 이후 계속 보유하는 추세 전략은 다른 가설이다. 교체 로직 추가와 동시에 원래 청산 기준을 없애면 어느 변경이 영향을 줬는지 알 수 없다. ETF 추세에는 코스피 눌림목의 SMA20 회복 청산을 자동 이식하지 않는다.

## 4. 좋은 후보가 나왔을 때의 교체 판단

### 같은 기준으로 비교할 것

신규 진입 적격 여부와 보유 가치 평가를 분리한다. 이미 보유한 주식이 RSI 35~50이나 눌림 범위를 벗어났다는 이유만으로 점수를 0으로 만들지 않는다. 후보와 보유를 **같은 시각·같은 상품군·같은 평가 기간**으로 비교한다. 데이터가 누락된 보유를 “최하위 점수”로 처리해 임의 매도하지 않는다.

첫 단계는 기존 상대강도·추세 점수를 적격 판정과 분리해 보유에도 계산하고, 당시 비교 집단 안의 백분위로 기록하는 것이다. 누락 상대강도를 0으로 대입해 교체를 결정하지 않는다. 이 규칙 점수는 연구용 순위이며 미래 수익률이나 확률로 표시하지 않는다. 현재 시스템에 검증된 “확실히 좋은 후보” 판별기가 있는 것은 아니다.

보유 수, 교체 수, 최소 보유기간을 분리하는 구조는 Qlib의 TopkDropout에서도 확인된다. 다만 그 알고리즘을 그대로 가져오거나 높은 순위가 반드시 높은 수익을 낸다고 해석하지 않는다. [Qlib 공식 전략 문서](https://qlib.readthedocs.io/en/stable/component/strategy.html), [공식 API](https://qlib.readthedocs.io/en/stable/reference/api.html#qlib.contrib.strategy.TopkDropoutStrategy).

### 교체 조건

아래 조건을 모두 만족하는 한 쌍만 선택하는 정책을 우선 검증한다.

1. 일반 청산을 반영한 뒤에도 보유/예약 자리 또는 다른 자원 한도가 부족하다. 자리가 있고 자금·위험 여유도 있으면 기존 보유를 팔 필요가 없다.
2. 신규 후보가 진입·거래대금·변동성·가격 허용 폭·데이터 품질 조건을 통과한다. 실제 주문 가능 수량이 0인 후보 때문에 보유를 팔지 않는다.
3. 기존 보유는 전략 관리 수량이며 실제 매도 가능하다. 수동 보유와 거래정지 종목은 교체용 매도 대상으로 강제 사용하지 않는다.
4. 신규 후보는 상위 진입 구간, 기존 보유는 그보다 넓은 유지 구간 밖에 있고 점수 차이가 충분하다. 동률이면 보유를 유지한다. 하나의 순위 경계에서 매일 사고팔기를 반복하지 않게 진입·교체 경계를 다르게 둔다.
5. 추정 교체 비용과 체결 불확실성이 허용 예산 안에 있다. 현재 점수를 비용 퍼센트와 직접 빼지 않는다.
6. 교체 후 전체 투자 비중·총 손절 위험 예산·업종/지수 노출·상관된 집중이 허용 범위다. 자금과 위험을 확보할 수 있는지도 실제 수량으로 재계산한다.
7. 최소 보유기간, 재진입 대기기간, 일별 교체 수와 회전율 한도를 만족한다. 이런 제한은 보호 목적의 청산에 적용하지 않는다.

예시 연구 설정은 하루 평가 1회, 자발적 교체 최대 1쌍/일, 최소 보유 3거래일, 교체 매도 후 같은 종목 재진입 대기 3거래일이다. **검증할 초기 후보이며 최적값·확정 운용값이 아니다.** 높은 진입 백분위, 낮은 교체 백분위와 최소 점수 차이는 소수 후보를 사전 등록한다. 기존 5종목과 비교할 보유 상한 10·20도 별도 실험 축으로 둔다.

### 비용을 넘는 우위의 의미

현재 연구의 비용 가정을 동일 금액 매도 A→매수 B에 적용하면 다음과 같다.

```text
매수·매도 수수료 1.5bp × 2 + 매도세 20bp + 슬리피지 5bp × 2
= 교체 금액의 약 33bp = 0.33%
```

증권사 청구액이나 현재 법정 세율을 확인한 값은 아니다. 별도 스프레드와 시장충격이 5bp에 포함됐는지 정의한 후 중복 없이 비용을 추가해야 한다. 거래 금액이 다르면 각 매도·매수 금액으로 다시 계산한다. 예컨대 20만원을 교체하는 이 가정의 비용은 약 660원이다.

검증된 수익 예측이 생기면 동일한 미래 평가 기간의 **교체 포트폴리오 기대 가치 − 유지 포트폴리오 기대 가치 − 증분 비용 − 불확실성 여유**로 판단한다. 실제 주문 비중, 대기 중 현금, 기존 보유의 남은 청산 정책, 공통 평가 시점의 청산 비용을 맞춘다. 이미 비용을 차감한 예측에서는 같은 비용을 다시 차감하지 않는다.

그 전에는 순위 차이·비용 한도·회전율 제한을 사용하는 규칙 후보를 shadow로 검증한다. “점수 20 차이이므로 0.33% 비용을 이긴다”는 계산은 성립하지 않는다. 거래비용과 신호 지속성을 함께 고려해야 한다는 연구를 설계 근거로 참고했다. 해당 논문의 모형·실험을 한국 주식의 효과 증명으로 사용하지 않는다. [Gârleanu·Pedersen, 2013](https://docs.lhpedersen.com/DynamicTrading.pdf).

## 5. 매도·매수 연결 실행

```text
장후 동일 시점으로 포지션·후보·비용·위험 평가
  → 일반 청산 계획 및 자리/자금 여유 확인
  → 남은 부족분에 한해 교체 쌍 선택·기록
  → 다음 주문 창에서 양쪽 거래 가능성과 후보 가격 재확인
  → 기존 보유 매도
  → 체결·잔여 수량·주문 가능액 대조
  → 신규 후보 재검사
  → 허용될 때만 신규 매수, 아니면 현금 유지
```

매도와 매수는 원자적으로 동시에 성공하는 거래가 아니다. 좋은 후보가 사라지거나 매수가 실패하면 현금이 남을 수 있으며, 이를 실패 모드와 성과 비용으로 기록한다.

| 상황 | 처리 |
| --- | --- |
| 기존 종목 매도 미체결/거래정지 | 보유 자리를 유지한다. 교체 대상 신규 매수를 선행하지 않는다 |
| 부분 매도 | 잔여 주식이 있으면 종목 자리도 남는다. 부분 체결 금액만으로 자리가 비었다고 판단하지 않는다 |
| 수동 보유와 전략 보유가 같은 종목 | 전략 수량만 매도. 계좌 전체에 잔여 보유가 있으면 종목 수 상한에서 그 자리는 남는다 |
| 주문 결과 불명/재시작 | 교체 의도 ID와 양쪽 주문 ID로 대조 후 이어간다. 결과 확인 없이 새 매도나 매수를 재전송하지 않는다 |
| 신규 후보 급등·품질 악화·주문 창 종료 | 매도 전이면 자발적 교체를 취소. 이미 매도됐으면 매수를 보류하고 현금 유지 |
| 교체 이유가 사라짐 | 미제출 교체 매도는 취소 가능. 제출 주문은 취소 확인 전까지 예약을 유지. 보호 청산 사유가 생기면 독립 청산으로 승격 |
| 자금/위험 상한만 부족 | 금액·위험 축소가 목적이면 부분 매도가 가능하지만, 종목 수를 줄이는 교체와 목적을 구분한다 |
| 1주 보유·소액 포지션 | 분할 후 0주·최소 주문금액 미달이면 분할하지 않고 사전 정의한 전량/유지 정책을 사용한다 |

일봉 기준선에서는 매도 체결을 확인한 뒤 같은 날 **동일 시가**로 신규 매수했다고 가정하면 안 된다. 교체용 매수는 보수적으로 매도 체결일 장후 재평가 후 다음 시가로 미룬 정책을 우선 비교한다. 당일 교체의 효과는 실제 관측 분봉/호가와 주문 지연을 사용한 별도 재생으로 검증한다. 기존 선확정 일봉 주문 계약을 몰래 바꾸지 않는다.

교체 상태는 `planned → exit_submitted → exit_partial/exit_confirmed → entry_recheck → entry_submitted → completed`와 `expired/cancelled/reconcile_required`를 영속화한다. 매도 접수, 완전 체결, 대조 완료를 분리하고 브로커가 반환한 실제 주문 가능액을 사용한다. 보호 청산 의도는 교체 쌍이 만료돼도 사라지지 않는다.

포트폴리오 총위험은 주문 수량을 정하는 단일 거래 예산과 구분한다. 예를 들어 보유의 현재 가격에서 손절선까지의 위험 금액과 신규 주문 예약 위험을 함께 계산하되, 갭·거래정지로 그 값을 초과할 수 있음을 명시한다. 정확한 위험 한도는 전략 검증과 계좌 운용 정책에서 정하며 종목 수 확대에 따라 자동으로 상향하지 않는다.

## 7. 검증과 선정 순서

1. **원장·데이터 선행 보정:** 감자/분할/배당/상폐·거래정지·가격 단위·공개 시각과 재진입/부분 매도 오류부터 해결한다. 현재 차단된 결과를 최적화 기준으로 쓰지 않는다.
2. **기준선 재생:** 현행 4개 청산 조건·5종목을 고정해 재현한다. 변경 전후 입력/코드/결과 해시와 독립 현금·수량·원가 원장을 대조한다.
3. **보유 수 비교:** 교체 없이 5·10·20종목. 전체 위험 예산을 맞춘 비교와 거래당 0.25%를 그대로 둔 위험 확대 비교를 분리한다.
4. **매도 정책 비교:** 같은 보유 수·진입·비용 조건에서 SMA20 전량 청산, 회복 후 추적 손절, 선택적 일부 청산+추적 손절을 각각 비교한다. 한 번에 모든 규칙을 추가하지 않는다.
5. **교체 순증 효과:** 같은 매도 정책·보유 수에서 교체 OFF/ON. 단순한 하위 교체는 비교군으로만 두고, 비용·점수 차이·최소 보유기간 제한의 효과를 분리한다. 연쇄적인 현금·후속 거래 변화까지 전체 포트폴리오를 재생한다.
6. **미사용 구간 평가와 shadow:** 순차 검증과 최종 미사용 평가 구간을 고정한다. 이미 반복 확인한 이번 전체 기간을 새 최종 테스트로 부르지 않는다. 장중 교체는 관측 자료를 확보한 뒤 별도 모의로 검증한다.

보고 지표는 비용 후 수익·최대낙폭·회전율·평균 투자 비중·평균 보유 수·현금 대기일·정지 평가액·업종 집중·실현손익뿐 아니라 교체 횟수, 교체 비용, 새 종목 매수 실패, 재진입 반복, 보호 청산 지연, 최고 이익 대비 반환분, 최대 불리 변동을 포함한다. 교체하지 않았을 때의 결과는 같은 시점의 그림자 포트폴리오로 비교한다. 사후 수익을 본 뒤 성공한 교체 쌍만 고르지 않는다.

최고 이익과 최대 불리 변동은 사후 평가 지표이며 의사결정 시점에 미래 경로를 입력하지 않는다. 종목별 교체 가정만 합산한 값은 전체 자금 경로가 달라지는 실제 포트폴리오 성과와 구분한다.

### 구현 시 필요한 회귀 시나리오

| 시나리오 | 통과 조건 |
| --- | --- |
| 신규 후보가 조금 우세/동률 | 기존 보유 유지, 불필요한 교체 주문 0건 |
| 빈 자리·가용 위험이 있음 | 불필요한 기존 매도 없이 신규 후보만 검토 |
| 손절과 교체 제한 동시 발생 | 최소 보유기간·쿨다운이 보호 청산을 막지 않음 |
| 교체 대상 전량 매도/부분 체결/수동 잔여 | 실제 계좌 자리와 예약 수 일치, 자리 확보 전 후속 매수 없음 |
| 거래정지·하한가·가격 누락 | 가짜 체결 없이 의도·수량·평가 단위 보존 |
| 결과 불명·취소 중 추가 체결·재시작 | 양쪽 주문 중복 없음, 대조 후 확정 잔량으로만 진행 |
| 전량 청산 후 재진입 | 새 position_id와 진입일, 새 초기 위험·최고 종가 생성 |
| 부분 매도 | 잔여 보유의 기존 손절선·원가 배분·실현손익 정확 |
| 추적 손절·기업행동 | 미래 고가 참조 없음, 보호선 임의 완화 없음, 가격/수량 기준 일치 |
| 장중 교체 | 실제 매도 확인 뒤의 시세로 신규 판단, 이전 시가로 소급 체결 없음 |
| 비용·점수 | 순위 점수를 수익률로 사용하지 않음, 증분 비용 이중 차감 없음 |
| 손실 중지·후보 창 만료 | 자발적 교체 중단, 독립 보호 청산과 대조는 계속 |

이번 문서의 비교안은 아직 구현·백테스트하지 않았다. 이번에 실행한 검증은 현행 결과의 구조 재집계와 두 합성 재현이다. 이전 253개 테스트 통과는 새 교체/분할/추적 손절 정책의 검증을 뜻하지 않는다.
