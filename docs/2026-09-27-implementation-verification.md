# 구현 및 검증 기록 — 2026-09-27

계획의 로컬 구현과 외부 의존성 없이 가능한 검증을 수행했다. 실제 자료 연구 검증, 장중 한투 모의 주문 전체 경로, 연속 실제 운용, 한 달 관찰은 별도의 외부 검증이다. 그 준비와 실행 절차는 [사용자가 할 일](user-actions.md)에 모았다. 실전 자금 거래와 원격 호스팅은 이번 범위가 아니다.

## 자동 검증

- Python 전체 **226개 통과**, 별도 프로세스의 실행권 탈취 차단 회귀 포함. Ruff 검사/포맷은 백엔드와 계약 내보내기 스크립트 **56개 파일 통과**. FastAPI/Starlette 테스트 클라이언트의 httpx 사용 중단 예정 경고 1개가 있으며 테스트 실패는 아니다.
- 프론트 단위 **10개**, 브라우저 **7개** 통과. 펼친 연구 폼·전략·주문·대시보드의 axe WCAG A/AA 검사와 320px 화면 포함.
- 생성된 OpenAPI→TypeScript 계약 검사, TypeScript/프로덕션 빌드, 프론트 포맷 검사 통과. 변경된 임시 스키마가 계약 검사에서 실패하는 것도 확인.
- 실제 로컬 API+작업자+브라우저: 매수 의도→체결→보유 증가→매도→보유 복귀, 합성 자료→피처→백테스트→Ridge 학습→일별 보고.
- 정적 배포의 8개 직접 경로/새로고침/번들 로드 검사. 단일 실행 스크립트의 API+작업자 시작과 Ctrl+C 종료, 남은 프로세스 없음 확인.
- 주문 응답 유실, 재시작, 부분 체결/취소, 정정 예약 해제, 다중 주문 노출, 미확정 명령, 계좌 현금 외부 변동, 늦은 비용 증빙, 전체 DB/artifact 복원을 검증.
- 버전 관리 대상 107개 파일에 대해 현재 실제 자격증명 값과 대조한 검사에서 일치 0건. `.env`와 `.local`은 Git 제외.

## 최종 판정

G0의 로컬 회귀·계약은 통과했다. G1은 앱의 실제 읽기와 공개 현재 마스터까지 확인했고, 전체 역사 자료 확인은 남았다. G2의 실제 장중 주문/체결/취소/정정, G3의 실제 PIT 데이터 연구, G4의 실제 연속 세션, G5의 한 달 관찰은 완료로 표시하지 않는다. 현재 모의 주문 전송/자동 운용은 기본 비활성이고 실전 주소는 허용하지 않는다.

미확인 비용을 0원으로 간주하거나 미래에 공개된 공시/수정자료를 과거 입력에 채워서 검증을 통과시키지 않는다. 실험 성과가 좋다고 실전 전환을 자동 활성화하지 않는다.
