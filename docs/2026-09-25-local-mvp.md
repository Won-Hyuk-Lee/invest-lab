# 로컬 첫 버전 작업 기록

날짜: 2026-09-25

## 반영 사항

- 7·30·90일 등락률을 거래일 관측치 기준으로 확정.
- Python/FastAPI + React/TypeScript/Vite로 로컬 화면과 API 구현.
- 도메인/유스케이스/포트/어댑터 분리. 현재 SQLite와 샘플 시세 어댑터 조립.
- 대시보드, 종목 탐색·상세, 전략 버전 관리, 로컬 모의매수 기록 구현.
- 현금·비중 제한, 금액 Decimal 계산, 트랜잭션, 주문 식별자 중복 방지.
- `.env` 유지 및 무사용. 한투 API 호출·실전 주문·배포는 수행하지 않음.
- 의존성 잠금 파일, 로컬 실행 스크립트, 설계 문서 추가.

## 확인 결과

- 백엔드 27개 테스트 통과: 거래일 계산, RSI, 부족 이력, 거래량, 반등 조건, 데이터 검증, 주문 중복/제한, 전략 충돌, API 경계, 내부 계층 의존성.
- Ruff 검사 및 포맷 검사 통과.
- TypeScript 검사 및 Vite 프로덕션 빌드 통과.
- Edge 기반 브라우저 확인 통과: 대시보드, 검색, ETF 필터, 차트, 모의매수/잔고, 전략 새 버전 저장, 검토 기준 필터, 상세 화면 전략 갱신, Esc 닫기, 주문 기록.
- 1440px 데스크톱과 390px 모바일 화면을 캡처해 검토. 모바일 대시보드·종목·전략 화면의 페이지 가로 넘침 없음. 종목 표는 내부 가로 스크롤 사용.
- 브라우저 검증은 `.local/browser-verification.db`로 분리했고 사용자용 `.local/workspace.db`에 테스트 주문을 남기지 않음.
- Starlette의 테스트 클라이언트가 httpx 호환성 폐기 예정 경고 1건을 출력함. 실행 및 테스트 실패는 없음.

## 남은 범위

현재 자료는 생성된 10개 종목 예제이며 실제 시세·전체 코스피 목록·실계좌가 아니다. 매도, 자동매매, 백테스트, ETF 특화 지표, 기업가치 분석은 미구현. 외부 공개용 인증도 아직 없으며 로컬 전용이다. 후속 순서는 `service-design.md`에 기록했다.
